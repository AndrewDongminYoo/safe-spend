# Apps in Toss withdrawal (2026-11-27)

`써도돼` no longer ships as an Apps in Toss mini app, and no new version goes to Apps in Toss.
The repository is archived on GitHub after this note.

## Why

Apps in Toss was the only platform of this app: storage, the banner advertisement and the bundle all run on the Apps in Toss SDK.
The platform brought few users and almost no revenue, and each release added maintenance work.
An Apps in Toss notice then said that from 2026-12-26 only mini apps with 500 organic visitors can run in-app ads.

## What stays

- The code, the specs and the plans, unchanged, as a record of the MVP.
- Removing the Apps in Toss SDK would leave no working app, because the storage layer and the advertisement are built on it, so the code was not changed.
